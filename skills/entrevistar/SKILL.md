# Entrevistar

## Propósito

Muitos planos parecem sólidos até serem questionados. Esta skill estrutura uma entrevista rigorosa para expor lacunas, suposições não verificadas e decisões adiadas antes que o plano vire execução.

## Quando usar

- O usuário pede para "estressar" uma ideia ou plano
- Uma decisão importante está sendo tomada com informação incompleta
- O usuário quer validar se pensou em todos os ângulos antes de agir

## Processo

1. **Mapeie a árvore de decisão.** Identifique os principais ramos do plano: escopo, público, recursos, riscos, critérios de sucesso.
2. **Resolva um ramo por vez.** Não pule para o próximo até o atual estar claro. Perguntas amplas demais geram respostas vagas; perguntas específicas geram decisões reais.
3. **Questione suposições, não apenas fatos.** Pergunte "por que você acredita nisso" tanto quanto "o que é isso".
4. **Registre decisões, não apenas respostas.** Cada resposta deve virar uma linha decidida no plano, não apenas uma nota solta.
5. **Feche com um resumo estruturado.** Ao final, apresente o plano revisado com todas as decisões tomadas durante a entrevista, destacando o que mudou desde a versão inicial.

## Diretrizes

- Uma pergunta de cada vez. Bloco de dez perguntas gera respostas superficiais.
- Prefira perguntas que forcem uma escolha (A ou B) a perguntas abertas demais, exceto quando a abertura for o ponto.
- Não aceite "não sei ainda" como resposta final em decisões críticas. Ajude a pessoa a chegar a uma decisão, mesmo que provisória.
- Se o usuário contradiz uma resposta anterior, aponte a contradição antes de seguir.

## Exemplo de abertura

"Antes de montarmos isso, vou te fazer algumas perguntas para garantir que o plano aguenta pressão. Vamos por partes: primeiro o escopo, depois os recursos, depois os riscos. Começando pelo escopo — [pergunta específica]."
